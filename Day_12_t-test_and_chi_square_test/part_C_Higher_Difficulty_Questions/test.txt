For each situation, decide:

one-sample t-test

two-sample t-test

paired t-test

chi-square test

a. Compare average exam scores of two different classes -> two-sample t-test
b. Check if weekend vs weekday affects product purchases -> chi-square test

e. Check if dessert choice (cake/pie/ice cream) depends on gender -> chi-square test
